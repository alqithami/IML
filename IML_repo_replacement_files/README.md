# IML: Institutional Monitoring & Ledger for Sequential Social Dilemmas

This repository accompanies the accepted article **“Institutional Monitoring and Ledgers for Cooperative Human–AI Systems: A Framework with Pilot Evidence”** in *Mathematical and Computational Applications*.

It provides a reference implementation of an **Institutional Monitoring and Ledger (IML)** wrapper for Sequential Social Dilemma (SSD) environments, with experiments in **Harvest** and **Cleanup**. IML keeps the underlying Markov game intact while adding an explicit institutional layer that can monitor norm-relevant events, record evidence in an auditable ledger, apply delayed sanctions or remedies, and expose review/contestation as explicit mechanism parameters.

## Repository contents

- `iml_ssd/` — core implementation of the IML wrapper, PPO training loop, evaluation pipeline, and analysis utilities.
- `configs/` — experiment configurations for all reported conditions across Cleanup and Harvest: Baseline PPO, Inequity Aversion, Social Influence, IML full, monitor-only, sanction-without-review, and high-review.
- `scripts/` — setup and execution helpers, including `install_ssd_no_ray.sh`, `run_sweep.sh`, and `run_full_sweep.sh`.
- `runs/` — per-run training/evaluation outputs, including models, logs, ledger traces, and evaluation CSVs when committed.
- `results/` — aggregated CSV summaries.
- `figures/` — figures generated by the public analysis pipeline.
- `robustness/` — evaluation-seed robustness and sensitivity analyses.
- `paper_artifact/` — manuscript source, compiled PDF, figures, tables, and paper-side result files.

## System requirements

- Python 3.9
- Linux or macOS recommended; Windows users should use WSL2 or another Linux-compatible environment
- `git`, `bash`, and either conda/miniforge or another compatible Python 3.9 environment

The SSD dependency used here is not compatible with modern Python/Gym/NumPy stacks without patching, so this repository provides a Ray-free SSD installer.

## Installation

```bash
git clone https://github.com/alqithami/IML.git
cd IML
conda env create -f environment.yml
conda activate imlssd
python -m pip install --upgrade pip setuptools wheel
bash scripts/install_ssd_no_ray.sh
python -m pip install -e .
```

A manual setup is also possible:

```bash
conda create -n imlssd python=3.9 -y
conda activate imlssd
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
bash scripts/install_ssd_no_ray.sh
python -m pip install -e .
```

## Smoke test

```bash
python -m iml_ssd.tools.smoke_test --env cleanup --num_agents 5 --steps 50
```

## Running experiments

Train one run:

```bash
python -m iml_ssd.experiments.train --config configs/cleanup_iml.yaml --seed 0
```

Evaluate one trained run:

```bash
python -m iml_ssd.experiments.evaluate \
  --run_dir runs/cleanup_iml_agents5_seed0 \
  --episodes 50 \
  --seed 0
```

For the full reported-condition sweep:

```bash
bash scripts/run_full_sweep.sh
```

This runs all reported conditions across Cleanup and Harvest with five training seeds. It then evaluates each trained policy under five evaluation seeds (`0 1 2 3 4`), aggregates the results, generates figures, and runs the statistical-analysis script.

## Aggregating existing runs

```bash
python -m iml_ssd.analysis.aggregate --runs_dir runs --out_dir results
python -m iml_ssd.analysis.plot --results_dir results --out_dir figures
python -m iml_ssd.analysis.statistics --results_dir results --out_dir results/statistics
```

If your run directories contain files such as `eval_seed0.csv` through `eval_seed4.csv`, you can rebuild the consolidated evaluation-seed tables with:

```bash
python rebuild_eval_seed_sweep.py
```

## Robustness and sensitivity analyses

The `robustness/` directory contains scripts and outputs for the additional analyses reported in the manuscript, including evaluation-seed robustness, paired deltas across conditions, and Cleanup sensitivity to false-positive rate and review probability.

Typical entry points:

```bash
python robustness/robust_eval_seed.py
python robustness/sensitivity_cleanup_iml.py
```

## Troubleshooting

If `social_dilemmas` is missing, rerun:

```bash
bash scripts/install_ssd_no_ray.sh
```

If `cv2` is missing, install OpenCV into the active environment:

```bash
python -m pip install "numpy<2" "opencv-python<4.13"
```

The project constrains NumPy to `<2` to remain compatible with the older SSD dependency stack.
